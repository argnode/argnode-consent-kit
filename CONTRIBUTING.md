# Contributing

Thank you for your interest in Argnode Consent Kit.

## Before you start

1. Read the [README](README.md). Make sure that your change agrees with how the tool works: no dependencies, consent default before any tag, equal Accept and Reject.
2. For large changes, open an issue first. Discuss the change before you write code.

## Contributor License Agreement (CLA)

Before we can merge a contribution, you must accept the [Contributor License Agreement](CLA.md).

The CLA assigns the copyright of your contribution to Argnode Oy. Your name stays in the project history and in the contributor list.

Why: Argnode Oy must hold the full copyright of the project. This lets Argnode Oy keep the project consistent, defend it, and offer other licences in the future.

How: when you open a merge request or pull request, a bot asks you to accept the CLA. Accept it one time. It then applies to all your contributions.

If you do not accept the CLA, we cannot merge your contribution.

## Rules for code

- Write simple code that a person can read easily.
- Use no external dependencies.
- Start all CSS classes and IDs with `ack-`.
- Write developer-facing text (comments, keys, docs) in ASD-STE100 Simplified Technical English.
- Add this header to each new source file:

